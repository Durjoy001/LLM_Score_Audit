So, why and what is Brilliance? 
Brilliance File Organizer Software aims to make file organization process
efficient and pain free for people who are in a trade where they have a lot
of clients and need to maintain large number of files relevant to each
clients. Accountants, lawyers, engineers, architects, consultants in various
fields, investigators, teachers, and many others will find this software
especially useful.
It can also be used as a photo library!
The basic idea is:
• The user creates Client Profiles.
• Attach files and folders to the Client Profiles.
• Add more relevant information such as tags, customs dates, amounts,
and description etc.
• Search for files using client's name, ID, tags, dates, and many techniques
to pin point a files or files that the user needs to retrieve.
• Search contents (e.g. TAX ID) scanned documents, PDF and image files
using Text.
• NOTE: Files are kept in the personal computer of the user. So, no internet
connection is necessary. No risk of data breach!
As an example - think of an accountant or a lawyer with 100s or 1000s of
clients over the years of his/her career. If the accountant receives a
request to retrieve a file from 6 years ago related to a specific client, how
tedious the task can be to search through 1000s of documents to find the
one in question. Brilliance File Organizer is here to rescue!
This is an ECM (enterprise content management system) for personal
computer users with the fraction of the cost!

Other tools included with the package
PDF Tools - A set of tools to manipulate PDF files. Convert many images,
office files etc in to PDF, merge multiple files, page copy or split PDF file to
create another, Password protect and un-protect.
Image to Text Tools - A set of tools to convert scanned images, PDF files,
office documents etc into Text documents. Brilliance automatically index
the extracted text so that they can be searched using Brilliance Search
Engine.
Expense Management Tools - A set of tools that lets you manage your
receipts. Attach amounts, dates and categories etc to produce yearly,
quarterly and monthly reports. Perfect for family and self-employed
people.
Task Management Tools - A set of tools to keep track of your small tasks
such as mortgage and immigration etc with files and notes attachments.
You can turn your task into a reminder.

Risks and challenges
We do not need any special permission from any 3rd party as I am the
founder, architect, main developer and copyright holder of this software
and the associated website.
The main risk that we faced during different phases is that we are building
this system for personal computer users who may or may not be proficient
in using computer applications. So, we really had to design it carefully to
make it as easy to use as possible.
We also had to tackle various issues such as license validation, download
server, payment processing etc. As we have run the project end to end, we
have come to realize that there are many hidden issues that must be
resolved before we can publish it to the public.
However, as being a Consultant Software Engineer and a Lead Architect by
profession with 17 years of experience, I am more than qualified to tackle
these issues. To me, these are minor issues. The major factor was effort
that I have put into it considering my family, my time, my other professional
engagements.
