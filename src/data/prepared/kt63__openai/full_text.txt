WebFrames is a sum of two custom, open-source software applications
and a "new" image format. It allows you to generate an animated file
containing bitmap and vector artwork with transparency that works in all 
major web browsers.
WebFrames automates a complex and tedious process of importing
images and exporting an SVG file with machine-accurate embedded CSS
animations.
It will be available as a visual editor for graphic designers (Sparkle Motion)
and as a command-line utility for developers.
What's different about it?
WebFrames images...
can contain bitmap and/or vector artwork
can be lossy (bitmap only) or lossless
do not have the quality limitations of GIF
do not have the browser limitations of APNG, MNG, WebP or video
do not require JavaScript or a plugin
use technology already present in current web browsers
While other web animation utilities allow you to animate an object, they do
not allow you to change the object itself in a key framed sequence. One
such example—as seen in the video—would be the comparison between
rotating the letter "S" and a cartoon snake travelling in a figure-eight knot.

WebFrames images seamlessly reach audiences that you would normally
have to make sacrifices for. Use them in emails, landing pages, "noscript"

Quick integration
WebFrames animated images can be linked to or embedded as you would
any other image (<img> or background-image). It remains a single asset
that is kept clear of any code unrelated to the design team. No need to
involve a developer.
Visual Editor (Sparkle Motion)
Sparkle Motion is a creative application allowing non-programmers to
create and edit animated images. It is planned for Mac, Windows and
Linux. It provides a visual interface to the command line utility that runs in
the background. The title of this editor is inspired by the movie Donnie
Darko and a nod to the silly "Sparkle" codename of Microsoft Silverlight
during Adobe/Macromedia Flash's reign.

Extend browser support of exports from
other animation programs
Using a component of WebFrames (smil2css), SVG animations exported
from other applications can finally be production ready in Internet Explorer
and without the use of runtime JavaScript. Additionally, animation
performance will be improved in other browsers such as Chrome and
Firefox.
How does it work?
WebFrames is a Node.js and CanJS application written almost entirely in
JavaScript with a few dependent libraries written in C/C++. It will be
available via the WebFrames website and NPM, making it extremely simple
(and fast!) to install on all major environments.
The exported image is a combination of CSS, SVG and a fair share of
previously unfathomed techniques.
WebFrames can import GIF, JPEG, PNG, SVG and export an animation with
or without image compression. Vector graphics will not be rasterized, but
will remain lossless. There's even an experimental feature where JPEG
compression is applied to transparent 24-bit PNG images (not compatible
with Safari 7).
Additionally, WebFrames will be released under the MIT License which
means you can do pretty much whatever you want with it. Include
WebFrames in anything you want and release under any license you want.
