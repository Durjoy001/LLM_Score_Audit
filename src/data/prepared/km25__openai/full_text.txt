As far as I know we have several web applications for video chat:

Hangout: http://www.google.com/+/learnmore/hangouts/ . Also you can
use web Skype: https://web.skype.com/, but actually all they require to
install some plugin for your browser or use flash.
I want to develop an application which is free from these restrictions.
For this application I'm using the following technologies:
1. WebRTC: http://www.webrtc.org/ for video communication.
2. SignalR: http://signalr.net/ for text messages and for original
connecting clients for video communication.
I started to work on this project several months ago and now I have a
working prototype: http://signalrtc.com/
Now this web app is working only on Chrome and Firefox, just because
not all browsers support WebRTC technology:
http://iswebrtcreadyyet.com.
Definitely IE and Safari don't support it, and I haven't tested with other
browsers yet.
And now video communication is possible only between two clients.

The goal of my project is following:
1. Create web application for video communication, working on almost
all modern browsers.
2. Add possibility to communicate for several users (web conference).
3. Allow only audio communication (if user don't have webcam or
doesn't want to use it).
3. Add screen sharing option (can be useful for technical support).
4. Add option for recording video and grab image.
5. Add option for user's registration. (I'm going to allow users use
service without registration).
6. Registered users can have history of their communication and text
messages.
7. Create version for mobile devices (Android, iOS, Windows) and
publish them in corresponding stores.
I'm going to offer this application for users for free, probably put some
ads on the page to earn some money and allow users to pay some fee
for ad-free option.
But mostly I'm going to offer this service to companies to embed page
for video communication in their web site. I see here market for tech
support companies and for recruiters. It can be replacement for
http://www.gotomeeting.ca/ or http://www.webex.com/ services.
I'm planning to complete above tasks during one year, but will try to do
this early.
What I need money for:
1. I'm going to make this project my full-time job, so I need some money
to live on.
2. I need to hire web and graphics designer to make site looks good in
order to attract client.
