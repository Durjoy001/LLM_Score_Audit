JavaScript, this project is for you!
If you answered "YES" to any of these questions,
Maybe it wasn't the subject you couldn't
get your head around, but the way it was
presented?
Visual learners retain information very differently than their left brained
counter-parts, and thus benefit from different approaches. Full color
illustrations help memory triggers as your brain never forgets an image,
metaphor or schema. One page of a visual guide can equal one chapter
of a conventional book as illustrations can make a world of difference
over strictly words on a page!
As a graphic and web designer who struggled many times myself to learn
programming, I looked all over the web and through so many books for
help! I searched for some sort of explanation of the concepts beyond
plain black and white text. I saw so many others failing and giving up at this
point that I decided I would have to take action myself and do something
about it. And so this project was born!
My goal is to create a VISUAL GUIDE that will work alongside conventional
books to help the more visually oriented learn and master JavaScript like
never before!
The book will focus on:
1. Building a strong foundation in programming
2. Understanding the basic concepts
3. Memorization of the terminology and syntax of the language.
