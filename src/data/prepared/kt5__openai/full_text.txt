There are many game enthusiasts out there who would love to learn how
to write mobile games but do not necessarily have the time to dedicate to
it.
Many Game Engines out there have a steep learning curve so creating a
full mobile game would take considerable time and effort.
We have created this course for all the coders who want to get into
creating their own mobile game using a 2D engine, and more importantly,
we have created this course to take you from 0 to hero in less than 6
hours.
Why Flame Engine
The Flame Engine is a minimalist 2D game engine that runs on top of the
Flutter framework. So it is light-weight with a small footprint.
This is perfect for mobile games.

Advantages of The Flutter Framework
One code base and multiple platform deployment. Basically write once,
and deploy to both iOS and Android. This is a huge advantage as it saves
you time and effort.
And this is great for mobile games since we do not rely on the specific OS
GUI as we basically take over the screen and create our own GUI from
scratch.

Assumptions
We assume that you have some coding experience and we also assume
that you know Flutter/Dart and have worked with it.
But in case you have not worked with Flutter do not fret!
The course is designed to help you with the setup and a solid
understanding of the language elements because of the architectural
approach.
So in reality all you need is experience with an Object Oriented language
such as Java, Swift, C#, C++, or TypeScript and you will be fine!
Why we launched this Campaign
We ask you for your pledges as we would love to create content that
would benefit anybody who wants to learn how to code a full 2D mobile
game but has limited time on their hands (donʼt we all?)
We need to polish the course, render it and optimize the game code and
we will be done, with your help that is!
Games offer an escape, and we love that facet of game development, so
we would love to show others how even with limited time you can focus
your energy to create a mobile game of your own.
Isn't there a game developer in all of us?
