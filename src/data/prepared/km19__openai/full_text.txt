Overview
CloudScript is an online app development studio. It's easy to use for
beginners and powerful for experts. The software is already in Alpha and
apps built with it are already being used by multiple companies. Funding will
be used for marketing and hiring people to advance the project to the next
level. CloudScript will be marketed as a subscription based hosting service
for your apps built with the editor. Since everything is in the cloud you can
resume work on your CloudScript project from any computer in the world.
Collaboration tools allows multiple people to work on a single project without
conflicts.
Multiplatform - Build your app once
CloudScript apps run on every platform: Windows, Android, Chromebook,
iOS, Mac and Smart TVs. This means you only have to create one version of
your app and can be certain it will behave the way it should everywhere!
What is CloudScript?
CloudScript is a web-based integrated development environment for web
applications. It has the power of high-end development suites like Visual
Studio but with the user-friendliness of solutions like Wix or Squarespace.
CloudScript is perfect for small and medium size businesses who need a
quick and effortless way to build software such as inventory and assets
management, communication, booking, scheduling. It's easy for beginners

How will the funding be used?
Since the project is already built and functional, funding will be used to
market the product and cover initial server costs and hire staff for further
testing, development and support.
Risks and challenges
The project is already built and functional. Apps built with CloudScript are
being used by companies such as Just-Eat Canada, DeliveryDirect,
OrderIn.ca and GeoDispatch so that's one challenge out of the way.
Going forward I think the pricing structure/business model may have to be
adjusted to offer the best price, cost and features ratio.
Initial demand may become overwhelming. We may have to limit the amount
of first customers we can sign up to be able to offer adequate support.
