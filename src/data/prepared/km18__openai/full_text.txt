What is Seeed?*
Seeed is an easy-to-use website that allows you to create a strong
password without worrying about forgetting it. Unlike random password
generator websites, Seeed allows for easily recovering those passwords.
Seeed Logo. Seeed will be available as a website, desktop application and a mobile
application.
It is great if you want to have multiple unique passwords for each
service you sign-up for while only needing to remember one password.

Seeed uses what are called Seeds, hence the name. Seeds, along with a
master password, are used to generate and regenerate passwords.
How do you use it?*
As an example, letʼs say you want to use Seeed to create a password for
Facebook, you would enter your master password and a seed. The master
password is a strong password that you create that should never change
unless of course someone unwanted figures it out. The seed is something
unique and related to the service you are creating the password for, for
example, you can use the name of the service.
Simply enter some easy to remember info...
In this example, we would put something like “yt&37m” as our master
password and “facebook” as our seed. Then, select whether you want
symbols and/or capital letters. It is recommended that you keep these
settings enabled unless the website you are using the password for
doesnʼt allow it. Then, all you have to do is click and hold the button and
the password will appear!
If you want to copy the password, click the “Copy to Clipboard” button.
Once you are done using the password and you used the copy feature,
simply clear the clipboard by clicking the “Clear Clipboard” button. It will
now be cleared with a clear message. Just say you want to use it on
Twitter. All you need to do is change the seed to “twitter” and you will have
a brand new password for twitter.

Is Seeed safe?*
Of course. Since this website deals with passwords, I have tried to make
this the most secure platform as possible. Seeed does not run any server
side code except to count how many times the service has been used. The
actual algorithm that generates your password is completely run on the
device you are using. Therefore, Seeed does not store any passwords,
seeds or master passwords at all. All it stores is how many times the
website was used. If you want proof, you can even visit the Seeed Github
page and read the code yourself.
Please note that the generator algorithm on the demo website is not safe at
the moment. It will be changed after the Kickstarter is funded. It is just
there to demonstrate the functionality.

Does Seeed have any weaknesses?
The only real weakness of using Seeed is if the person who is trying to
hack you knows you are using Seeed. In most cases though, if someone is
trying to hack your password, there is no way they can know if it was
generated with Seeed. If they are trying to bruteforce attack it to figure it
out, it would takes years to figure out. Even then, it would be very hard to
reverse the Seeed algorithm and get the master password.
What will Seeed cost to use?
Seeed is meant to be completely free to use when released. This is why
there is a Kickstarter campaign and Patreon funding, to pay the expenses
of running it to give all users a free, equal and ad-free experience.

I got the idea because my dad was always forgetting his passwords and
he wanted a way to safely store passwords and also be able to access
them quickly. I decided to try to find a way to do this without having to
store the passwords. I was doing a project on Perlin Noise for college at
the time and with that on my mind, I got the idea for Seeed. Perlin Noise,
like Seeed, uses a "seed" to create something that seems random but is
created from a seed and creates the same thing everytime.
Thatʼs the beauty of Seeed, strong password generation without
worrying about forgetting it. Passwords are not stored at all. There are
ZERO downsides to Seeed.
