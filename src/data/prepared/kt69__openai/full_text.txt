Funding period
bbPress Notify Pro is the evolution of the popular bbPress Notify (no-
spam) plugin. Written from scratch, it will contain all of the features of the Dec 13 2014 - Jan 12 2015 (30
original Notify plugin plus several improvements requested by users over days)
time.
Messages 
Send out HTML emails as well as text;
Notification frequencies include immediate, daily digest, and weekly
digest;
Extra template shortcodes such as "lead-in text", "top 10 topic/reply
list", and "topic/reply list" for digests.
User Interface
Users can specify which forums they receive notifications for (eligible
forums controlled by an admin);
Messages can contain an opt-out link, inserted into the template by a
shortcode;
Admin Control/Settings
Admins set the time of delivery for daily digest messages, and date/time
for weekly digest messages;
Admins can specify to which forums users are allowed to subscribe;
Roles can be used to control delivery;
Enable Background delivery (via WordPress cron job)
Risks and challenges
My main concern will be to handle sending mail-outs on Godaddy servers.
In my experience, they kill any process (web or not) that runs for more than
30 seconds.
