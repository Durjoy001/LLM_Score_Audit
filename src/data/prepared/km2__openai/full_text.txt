7/13/26, 1:14 PM Learn Python VISUALLY (3) by Ivelin Demirov — Kickstarter
Being a web and graphic designer, the struggles involved in learning
programming often led me deep in to books and all over the internet in
search for help. In search for some explanation that would make the
concepts simpler, easier to understand. And as I saw others failing or
giving up all together, I knew I had to make a move. Thus, this project came
to life.
THE BOOK WILL FOCUS ON:
1. Understanding the basic concepts
2. Building a strong foundation in programming
3. Memorization of the syntax and terminology of the language
4. Work on real world projects
5. Practice, practice, practice
All this will be achieved through the use of Metaphors, Real life objects
Analogies and Simple Exercises that are so much fun to do.
Associating a Python concept with real life objects followed by a brief
example makes a lot of sense:
Full colour illustrations aid in memory trigger as your brain hardly forgets
an image, schema or metaphor. In fact, one page of a visual guide can
equate to a chapter in a conventional book;
