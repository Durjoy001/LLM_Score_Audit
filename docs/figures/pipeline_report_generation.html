Evidence-Grounded Proposal-Screening Pipeline — Report Generation

Nine-stage pipeline that turns a heterogeneous proposal document into a rubric-scored, evidence-linked expert-style report. Every stage persists an auditable, structured artifact instead of passing only free-form text between steps — the property the downstream evaluation audit (Fig. A2) depends on.

Phase I · Stages 1–5— ingest the document and structure it into source-linked, dimension-tagged evidence
1

Document Upload

Accepts PDF, DOCX, PPTX, TXT, Markdown. Preserves page / slide boundaries, document identifiers, and source metadata.

out: paginated source + metadata
2

Text / OCR Extraction

OCR on scanned or image-heavy pages; vision processing converts visible tables, charts and diagrams into textual evidence.

out: extracted text corpus
3

Atomic Fact Extraction

LLM chunks the corpus into atomic propositions, each tagged with source location, evidence span and a tentative review dimension.

out: atomic facts (source-linked)
4

Dimension Construction

Facts assigned to the five dimensions; builds a provenance-linked evidence packet per dimension — supporting facts, adverse facts, missing evidence, risks, mitigations.

out: evidence packets × 5 dims
5

Question Generation

Per-dimension questions covering rubric criteria, evidence sufficiency, risks, mitigations and unresolved uncertainties.

out: dimension question sets
flow continues below➤
Phase II · Stages 6–9— answer evidence-grounded questions, assemble the report, and compute rubric scores
6

LLM Answering

Structured schema per answer: direct response, cited factual claims, source pointers, confidence, caveats — general domain knowledge kept separate from cited evidence.

out: structured Q&A records
7

Answer Selection / Post-Processing

Candidate answers checked for schema validity, dimensional relevance, evidence linkage, confidence and internal consistency.

out: validated answer set
8

Expert-Style Report Generation

Compiles retained Q&A evidence into an executive summary, dimension-level findings, evidence gaps, scores and a recommendation.

out: expert-style draft report
9

Rubric Scoring

Applies the explicit expert rubric. Blends evidence-oriented QA score with holistic investment-judgment score: s = λ·vinvest + (1−λ)·qQA, λ = 0.90.
